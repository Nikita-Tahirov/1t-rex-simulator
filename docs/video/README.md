# Видеозапись прогонов сценариев виртуальных экспериментов

Видеозапись прилагается к электронной версии ВКР как файл
`scenarios.mp4`. Раскадровка зафиксирована в Приложении Ж работы.

## Подготовка к записи

1. Открыть симулятор по адресу `https://rex-1t.web.app` в браузере на основе
   Chromium (Chrome/Edge). Для автоматической записи используется окно
   1280 × 720; для ручной OBS-записи допустимо 1920 × 1080.
2. Убедиться, что в правой панели индикации:
   - режим `Ручной` для начальной демонстрации;
   - камера `Орбита`;
   - выбран сценарий `figureEight`;
   - значение `seed = 20260428` (значение по умолчанию).
3. Для воспроизводимой записи из локального стенда использовать:

   ```powershell
   npm run video:record
   $webm = Get-ChildItem docs/video/_recording/page@*.webm | Sort-Object LastWriteTime -Descending | Select-Object -First 1
   ffmpeg -y -i "$($webm.FullName)" -c:v libx264 -pix_fmt yuv420p -movflags +faststart docs/video/scenarios.mp4
   ```

   Скрипт `video:record` запускает тот же контур Playwright/Chromium, что и
   E2E-проверки, и последовательно включает четыре демонстрационных миссии.
4. Для ручной записи можно использовать OBS Studio (свободная программа с открытым исходным кодом):
   - источник: захват экрана или захват окна браузера;
   - кодировщик: x264, CRF 18, профиль `medium`;
   - разрешение: 1920 × 1080, 60 кадров/с;
   - звук: отключить (звук в видео не нужен).

## Сценарий записи (≈1–3 минуты)

### Эпизод 1. Обзор интерфейса (00:00 — 00:10)

В живом режиме:
- показать сцену с роботом 1T-REX и аренной 14 × 14 м;
- кратко проехать роботом WASD: движение вперёд и поворот;
- показать вкладки панели: «Полётная», «Сенсоры», «Инженерная»;
- показать переключатели «Режим» (Ручной/FSM/BT) и «Камера» (Орбита/Следом/Спина/Сверху).

### Эпизод 2. Сценарий 1 — «Восьмёрка» (≈00:10 — 00:25)

1. Выбрать в панели сценарий `figureEight`.
2. Камера → `Орбита`, отдалить вид сверху.
3. Нажать `Старт`. Автопилот сценария ведёт робота по траектории Лиссажу.
4. Показать движение робота, изменение метрики и активность панели индикации.

### Эпизод 3. Сценарий 2 — «Объезд препятствий» (≈00:25 — 00:40)

1. Сценарий `obstacleAvoidance`. Режим — `BT` (дерево поведения).
2. Камера `Спина`.
3. Робот стартует, объезжает препятствия и движется к финишной зоне.
4. Показать метрику времени со штрафом за столкновения.

### Эпизод 4. Сценарий 3 — «Поиск и удар» (≈00:40 — 00:55)

1. Сценарий `searchAndStrike`. Режим — `FSM` (конечный автомат).
2. Камера `Орбита`.
3. Показать переходы FSM в карточке состояния: IDLE → SEARCH → ENGAGE.
4. Робот наводится на цель и движется к контакту.

### Эпизод 5. Сценарий 4 — «Удар ротором» (≈00:49 — 01:02)

1. Сценарий `spinnerImpact`. Режим — `BT` или ручной режим с пилотным контуром сценария.
2. Камера `Следом`.
3. Робот раскручивает вертикальный ротор, идёт на бронепанель и фиксирует `armorHit`.

### Финальный кадр / сопровождение

В электронном комплекте рядом с видео должны лежать JSON-протоколы трассировки или ссылка на них. На защите важно проговорить, что видео — иллюстрация, а проверяемый результат — протокол трассировки + `verification`.

## Постобработка

- Нарезка эпизодов и склейка — DaVinci Resolve (free) или Shotcut.
- Заголовки эпизодов в 4 пт PT Sans (шрифт ВКР), внизу слева, длительность 3 с.
- Без музыкального сопровождения.
- Фактический файл `scenarios.mp4`: H.264, MP4, 1280 × 720, 25 кадров/с, длительность ≈54,5 с.
- При ручной перезаписи через OBS допустим экспорт 1920 × 1080, 60 кадров/с.

## Воспроизводимость

При `seed = 20260428` (значение по умолчанию в `симулятор/src/store/scenario-store.ts`)
повторный прогон любого сценария даёт сопоставимый JSON-протокол с теми же
метаданными, summary-полями и результатом `verification`. Доказательным
артефактом является не сама видеозапись, а сохранённый протокол трассировки вместе с
PASS/FAIL-проверкой.
