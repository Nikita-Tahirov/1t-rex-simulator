# /verify

Выполнить:

```bash
npm run verify
```

Если падает:

1. Зафиксировать первый красный step.
2. Найти корневую причину.
3. Исправить.
4. Добавить regression-test, если дефект мог вернуться.
5. Повторить `npm run verify`.
